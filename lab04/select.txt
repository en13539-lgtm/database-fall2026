## Basic Select
postgres=# SELECT name, age FROM students;
 name  | age 
-------+-----
 Alice |  21
 Bob   |  23
(2 rows)


## WHERE
postgres=# SELECT name, age FROM students WHERE name = 'Alice';

 name  | age 
-------+-----
 Alice |  21
(1 row)
